  - `--bw-*` holds action, link and control-border colors.
  - `--bw-control-line #73767d` is for control borders; `--lg-line` is for dividers only.
- **Merge conflicts with `dev` resolved to the ESPN side.** This dropped the big-room-demo Lounge colors and Big Shoulders headings and Kevin's room TV-viewing CSS (06a239f). The Big Shoulders font files and `fonts.css` faces are still present but unused.
- **Scouting notes were deliberately rewritten** to short role notes with no nicknames (plan §21). Server tests now check the notes are non-empty and that the fallback value is used, rather than that they contain the nickname.
- **T20 test changed on purpose:** the live region must contain only "Connection interrupted"; the ticking age stays outside it (A03).
- **Unchanged invariants:** `/tv` is still the default TV (`/tv2` is the alternate); fixed seed IDs; no real teams in committed data; offline/fallback modes; MCP tools under 500 ms (from `CLAUDE.md`).
- **QR only in the lobby phase**, hidden below 1000px width. The code and URL text remain the accessible join route.
