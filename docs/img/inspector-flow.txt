Quirks / friction
- Inspector 2.x UI has no "List Tools" button: tools load automatically on connect (TOOLS/LIST in protocol log); custom headers live in Server Settings > Custom Headers, not the Add-server dialog.
- CLI exits rc=5 and prints only {"error":{"code":"tool_is_error",...}} on isError results; the useful message/errorCode is in stdout JSON content.
- Game clock runs at speed 4 vs real time, so make_pick via `npx inspector --cli` (2.5 s startup per call) often misses the 10 s window; use propId and call the CLI js directly.
- make_pick without propId targets the currently active prop; a stale choice string yields NOT_FOUND rather than PICKS_LOCKED.
- No Avast/loopback hang seen on localhost; no need for 127.0.0.1.
